# RideClimbPRO V1 candidate — Build 16

This build keeps the validated trainer-control path and adds the V1 product UI:

- native Wahoo/KICKR virtual shifting with validated 24-ratio table
- universal 1x/2x drivetrain setup using actual chainring and cassette teeth
- automatic real-ratio -> nearest native virtual-ratio mapping
- large Power 3s and Heart Rate dashboard tiles
- independent FTP and HRmax intensity colors
- generic Bluetooth Heart Rate Service support
- GPX elevation profile with current-position marker
- compact grade/cadence/speed/gear metrics
- diagnostic details moved behind a disclosure section
- CSV includes raw power, Power 3s, HR, requested ratio, native gear and native ratio
